# VFang v0.9.9 Arch-Family Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release VFang 0.9.9 with first-party x86_64 Pacman packages, one-command installation on Arch Linux, CachyOS, and conforming `ID_LIKE=arch` derivatives, and clean-container Arch/CachyOS release gates.

**Architecture:** Add one upstream-Arch-built split package pair (`fang`, `fangd`) and reuse the existing service, sysusers, desktop, icon, daemon/app version bounds, installer safety checks, and immutable-release model. Extend the installer with a third `pacman` family whose packages are authenticated and inspected before elevation, then test the identical artifacts on current Arch and the official CachyOS container.

**Tech Stack:** Bash, Node.js 22 test runner, Rust/Cargo, npm/Tauri 2, Arch `makepkg`/PKGBUILD, Pacman, GitHub Actions, systemd, Xvfb.

**Reference spec:** `docs/superpowers/specs/2026-08-08-v0.9.9-arch-family-support-design.md`

## Global Constraints

- The finished release version is exactly `0.9.9` and package release is
  exactly `1`. Tasks 1–5 intentionally remain version-derived from the current
  `0.9.8` workspace until Task 6 performs the single synchronized bump.
- Release architecture remains baseline `x86_64`; do not add x86-64-v3, x86-64-v4, Zen, aarch64, or i686 artifacts.
- Direct platforms are upstream Arch Linux (`ID=arch`) and CachyOS (`ID=cachyos`).
- Other Arch derivatives are accepted only when `ID_LIKE` contains the exact token `arch`, and receive the compatible-family warning.
- Publish exactly `fang-0.9.9-1-x86_64.pkg.tar.zst` and `fangd-0.9.9-1-x86_64.pkg.tar.zst` as the Pacman pair.
- The desktop package requires `fangd>=0.9.9` and `fangd<0.10.0`.
- The immutable v0.9.9 release contains exactly eight assets and `SHA256SUMS` contains exactly seven canonical entries.
- Preserve all pre-elevation checksum, metadata, architecture, version, and downgrade validation.
- Never run `pacman -Sy`, silently upgrade the operating system, pass `--nodeps`, or disable the user's Pacman signature policy.
- Keep `packaging/install-from-source.sh` Debian/Ubuntu-only; only improve its unsupported-family guidance.
- Build the package pair once on upstream Arch and test those exact files on both Arch and CachyOS.
- Keep DEB and RPM payload behavior unchanged except for v0.9.9 version synchronization and shared packaging-asset paths.
- Do not publish to AUR, an Arch repository, or a CachyOS repository in this release.

- [ ] **Step 7: Implement the package producer**

Create `packaging/arch/build.sh` with this control flow:

```bash
#!/usr/bin/env bash
set -euo pipefail

ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)"
OUTPUT="${1:-$ROOT/target/arch-dist}"
[[ $OUTPUT == /* ]] || OUTPUT="$ROOT/$OUTPUT"
[[ $EUID != 0 ]] || {
  echo 'run the Arch package build as an unprivileged user' >&2
  exit 1
}

for command in cargo node npm makepkg bsdtar; do
  command -v "$command" >/dev/null || {
    echo "missing build command: $command" >&2
    exit 1
  }
done

STAGE="$(mktemp -d)"
PKGDEST="$STAGE/packages"
trap 'rm -rf -- "$STAGE"' EXIT
mkdir -p "$PKGDEST" "$OUTPUT"

cd "$ROOT"
node app/scripts/version.mjs check
cargo build --release --locked -p fangd
(
  cd app
  npm ci
  npm run tauri build -- --no-bundle
)

install -pm0644 packaging/arch/PKGBUILD "$STAGE/PKGBUILD"
install -pm0755 target/release/fangd "$STAGE/fangd"
install -pm0755 app/src-tauri/target/release/fang "$STAGE/fang"
install -pm0644 packaging/fangd.service "$STAGE/fangd.service"
install -pm0644 packaging/fang.sysusers "$STAGE/fang.sysusers"
install -pm0644 packaging/fang.desktop "$STAGE/fang.desktop"
install -pm0644 LICENSE "$STAGE/LICENSE"
install -pm0644 app/src-tauri/icons/32x32.png "$STAGE/fang-32.png"
install -pm0644 app/src-tauri/icons/128x128.png "$STAGE/fang-128.png"
install -pm0644 app/src-tauri/icons/128x128@2x.png "$STAGE/fang-256.png"
install -pm0644 app/src-tauri/icons/icon.png "$STAGE/fang-512.png"

(
  cd "$STAGE"
  PKGDEST="$PKGDEST" makepkg --clean --cleanbuild --force --noconfirm
)

mapfile -t built < <(find "$PKGDEST" -maxdepth 1 -type f -name '*.pkg.tar.zst' -print | sort)
[[ ${#built[@]} == 2 ]] || {
  printf 'expected two Pacman packages, found %s\n' "${#built[@]}" >&2
  exit 1
}

find "$OUTPUT" -maxdepth 1 -type f -name 'fang*.pkg.tar.zst' -delete
declare -A seen=()
for package in "${built[@]}"; do
  metadata="$(bsdtar -xOf "$package" .PKGINFO)"
  name="$(sed -n 's/^pkgname = //p' <<< "$metadata")"
  case $name in
    fang|fangd) ;;
    *) echo "unexpected Pacman package: $name" >&2; exit 1 ;;
  esac
  [[ -z ${seen[$name]+present} ]] || {
    echo "duplicate Pacman package: $name" >&2
    exit 1
  }
  seen[$name]=1
  install -pm0644 "$package" "$OUTPUT/"
done
[[ -n ${seen[fang]+present} && -n ${seen[fangd]+present} ]]
printf 'Pacman artifacts:\n'
find "$OUTPUT" -maxdepth 1 -type f -name '*.pkg.tar.zst' -printf '%f\n' | sort
```

```bash
require_scalar() {
  local metadata=$1 key=$2 expected=$3
  local values=()
  mapfile -t values < <(sed -n "s/^${key} = //p" <<< "$metadata")
  [[ ${#values[@]} == 1 && ${values[0]} == "$expected" ]] || {
    echo "invalid $key metadata; expected exactly: $expected" >&2
    exit 1
  }
}

require_payload() {
  local members=$1 expected=$2
  grep -Fxq "$expected" <<< "$members" || {
    echo "missing package payload: $expected" >&2
    exit 1
  }
}

verify_package() {
  local package=$1 expected_name=$2
  local members metadata
  members="$(bsdtar -tf "$package" | sed 's#^\./##')"
  [[ $(grep -Fxc .PKGINFO <<< "$members") == 1 ]]
  ! grep -Fxq .INSTALL <<< "$members"
  metadata="$(bsdtar -xOf "$package" .PKGINFO)"
  require_scalar "$metadata" pkgname "$expected_name"
  require_scalar "$metadata" pkgver "${VERSION}-1"
  require_scalar "$metadata" arch x86_64
  require_scalar "$metadata" license GPL-2.0-only
}

[[ ${fang##*/} == "fang-${VERSION}-1-x86_64.pkg.tar.zst" ]]
[[ ${fangd##*/} == "fangd-${VERSION}-1-x86_64.pkg.tar.zst" ]]
verify_package "$fang" fang
verify_package "$fangd" fangd

fang_metadata="$(pkginfo "$fang")"
mapfile -t daemon_bounds < <(sed -n 's/^depend = \(fangd.*\)$/\1/p' <<< "$fang_metadata")
[[ ${#daemon_bounds[@]} == 2 ]]
[[ $(printf '%s\n' "${daemon_bounds[@]}" | grep -Fxc "fangd>=${VERSION}") == 1 ]]
[[ $(printf '%s\n' "${daemon_bounds[@]}" | grep -Fxc "fangd<${UPPER}") == 1 ]]

require_payload "$(bsdtar -tf "$fang" | sed 's#^\./##')" usr/bin/fang
require_payload "$(bsdtar -tf "$fang" | sed 's#^\./##')" usr/share/applications/fang.desktop
```

```js
export function parsePacmanPkgInfo(text) {
  const scalars = new Map();
  for (const line of text.split('\n')) {
    if (!line || line.startsWith('#')) continue;
    const match = line.match(/^([a-z][a-z0-9_]*) = ([\x20-\x7e]*)$/);
    if (!match) throw new Error(`malformed Pacman metadata line: ${line}`);
    const [, key, value] = match;
    if (['pkgname', 'pkgver', 'arch'].includes(key)) {
      if (scalars.has(key)) throw new Error(`duplicate Pacman metadata field: ${key}`);
      scalars.set(key, value);
    }
  }
  for (const key of ['pkgname', 'pkgver', 'arch']) {
    if (!scalars.has(key)) throw new Error(`missing Pacman metadata field: ${key}`);
  }
  return {
    name: scalars.get('pkgname'),
    version: scalars.get('pkgver'),
    arch: scalars.get('arch')
  };
}

export function inspectPacman(file, runCommand = commandValue) {
  const members = runCommand('bsdtar', ['-tf', file]).split('\n');
  if (members.filter((name) => name === '.PKGINFO').length !== 1) {
    throw new Error(`${path.basename(file)} must contain exactly one .PKGINFO member`);
  }
  return parsePacmanPkgInfo(runCommand('bsdtar', ['-xOf', file, '.PKGINFO']));
}
```
